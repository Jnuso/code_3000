# Security Policy

## Supported Versions

This repository contains coursework for CSE 3000. Security fixes target the latest code on the `main` branch.

| Version | Supported |
| --- | --- |
| Latest code on `main` | Yes |
| Older commits and other branches | No |

## Reporting a Vulnerability

Please report security vulnerabilities privately through GitHub:

1. Open the repository's **Security** tab and select **Advisories**.
2. Select **Report a vulnerability** to submit a private report to the maintainer, `@Jnuso`.
3. Include a description, affected files or commit, steps to reproduce, and potential impact. Remove passwords, tokens, and personal information from examples.
4. Use the private report to discuss clarification, fixes, and coordinated disclosure with the maintainer.

Private vulnerability reporting must be enabled in the repository settings for this option to appear. If the button is unavailable, open an issue asking the maintainer to enable private reporting without including any vulnerability details.

Please avoid publicly disclosing the vulnerability or submitting a public pull request that reveals it before a fix and disclosure have been coordinated.

## Security Announcements

Check the repository's [Security Advisories](https://github.com/Jnuso/code_3000/security/advisories) for published vulnerability notices and the commit history for fixes. To receive security notifications, use GitHub's **Watch** menu, select **Custom**, and enable **Security alerts**.

## Bug Bounty Program

This educational project does not offer a paid bug bounty program. Responsible vulnerability reports are welcome.
